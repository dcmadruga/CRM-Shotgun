    <div id="apresentacao">
        <hr>
        <h2>Apresentação</h2>

        <p>
            Este é um documento técnico que apresenta o formato de troca de dados com o fim de permitir a aplicativos de
            terceiros o cadastro automatizado de documentos para publicação no Diário Oficial dos Municípios de Santa Catarina.
        </p>
        <p>
            O cadastro automatizado de publicações pode ser útil para diversos sistemas de terceiros que armazenam ou
            geram documentos os quais precisam ser submetidos ao processo de publicidade oficial, como ferramentas de
            contabilidade e gestão de pessoal, ferramentas de controle legislativo, tributário e muitas outras.
        </p>
    </div>
    <div id="informacoes-gerais">
        <h2>Informações Gerais</h2>

        <p>
            A integração prevista neste documento é feita através de um web-service no modelo REST.
            Toda comunicação cliente/servidor ocorrerá via protocolo HTTPS (TLS 1.2), porta 443/TCP.
            São aceitos os métodos GET e POST, sendo seu uso discriminado neste documento.
            A autenticação utilizada é do tipo HTTP Basic Auth.
            O retorno é feito combinando os códigos HTTP padrão (200, 400, 401, 403 e 404) somados a um objeto JSON.
        </p>
        <p>
            A autenticação do tipo HTTP Basic Auth, com CPF e CNPJ, e X-API-KEY, deve ser feita em todas as requisições.
            O controle de acesso é o mesmo empregado para o login de cadastro de atos no site.
            Todas as publicações são cadastradas no nome do usuário autenticado e o acompanhamento delas é de inteira
            responsabilidade do usuário que a cadastrou.
        </p>
        <p>
            Todas as regras de publicação vigentes são aplicadas também aos documentos cadastrados por API.
        </p>
        <p>
            <b>Endereço base para as requisições:</b>
        </p>

        <div id="novos_cadastros">
            <h2>Novos Cadastros</h2>

            <p>
                <!-- Existem duas formas de cadastrar documentos no DOM.
                A primeira e mais comum, que visa à publicação do ato em uma Edição de uma determinada data deve ser -->
                A forma de cadastro mais comum, que visa à publicação do ato em uma Edição de uma determinada data deve ser
                feita pelo <a href="#cadastrar_ato_para_publicacao">"Cadastrar Ato para Publicação"</a>.
                <!-- Já na modalidade de item de acervo público, em que o ato não é publicado em uma determinada Edição do -->
                                    Para publicações instantâneas deve-se utilizar a opção <a href="#cadastrar_autopublicacao">"Cadastrar Autopublicação"</a>.
                                Já na modalidade de item de acervo público, o ato não é publicado em uma determinada Edição do
                DOM, mas fica armazenado e disponível mediante o mesmo sistema de pesquisa.
                Esse cadastro de documentos, normalmente antigos, é feito pelo
                <a href="#cadastrar_item_acervo_publico">"Cadastrar Item de Acervo Público"</a>.
            </p>
            <p>
                Ainda sobre os tipos de cadastros disponíveis, ressaltam-se <b>4 pontos importantes em
                    comum:</b>
            </p>
            <ol>
                <li>
                    Caso a categoria do Ato seja "1" ou "2", <a href="#metadados_categoria_1_2"> "Metadados para Leis e
                        Decretos (categorias 1 e 2)"</a> podem ser enviados.
                    <strong>Aqui enfatizamos que hoje os Metadados são obrigatóros para Itens de Acervo Público, mas
                        que também, futuramente, serão obrigatórios para Cadastros de Novas Publicações;</strong>
                </li>
                <li>
                    Caso a categoria do Ato seja "6, 7 ou 28", <a href="#metadados_categoria_6_7_28"> "Metadados para
                        Contratos, Convênios e Empenhos (categorias 6, 7 e 28)"</a> podem ser enviados.
                    <strong>Aqui enfatizamos que hoje os Metadados são obrigatóros para Itens de Acervo Público, mas
                        que também, futuramente, serão obrigatórios para Cadastros de Novas Publicações;</strong>
                </li>
                <li>
                    Basicamente a única diferença dos parâmetros desses cadastros é que para "Cadastrar Ato Para
                    Publicação" deve-se fornecer o parâmetro "Ato[data_publicacao]".
                                            Para "Cadastrar Autopublicação" a data de publicação será o momento presente e não deve ser informada.
                                        Por outro lado, para "Cadastrar Item de Acervo Público", fornece-se o parâmetro
                    "Ato[data_documento]".
                </li>
                <li>
                    Todos os cadastros retormam <a href="#resposta_padrao_novos_cadastros">Resposta Padrão para Novos
                        Cadastros</a>.
                </li>
            </ol>

        },
        "codigo":{
            "type":"integer",
            "description": "Código do Ato",
            "required":true
        },
    }
}
            </code></pre>

curl -X POST -u cpf_usuario:cnpj_empresa_integradora -H 'X-Api-Key: token_base64' "https://diariomunicipal.sc.gov.br/?r=remote/delete&amp;id=&lt;código_ato&gt;"
