# Propostas Argo

App (PWA) para a equipe gerar a Proposta Comercial em PDF, no celular e no computador.

- `index.html`: o app. Funciona sem internet depois da primeira abertura (exceto busca de CNPJ e cálculo de km).
- `parametros.json`: preços, textos e referências da equipe. Atualizado pelo botão **Publicar para a equipe** no modo administrador.
- Os dados do vendedor (nome, telefone, e-mail) ficam em cada aparelho.
